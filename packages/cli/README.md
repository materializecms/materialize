# @materializecms/cli

The materialize command: development, production with updates from the panel, site builds, backups, MCP.

```bash
materialize dev      # development, with the schema reloaded on every save
materialize start    # production, with the supervisor that applies updates
materialize build    # the static site in dist/client
```

It also has `install.sh`, the one-command VPS installation, and `compose.yaml` for Docker.

## Materialize

An open-source CMS with a visual editor: pages are designed on a canvas, and the site is made of fast static files. The panel speaks English and Italian. For a new site (Node 24 or later):

```bash
npm create materialize@latest
```

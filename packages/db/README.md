# @materializecms/db

Il database di Materialize: contenuti con bozze, pubblicazione e revisioni, utenti e sessioni (SQLite o libSQL).

Lo usa il server di Materialize: di solito non serve importarlo direttamente. Funziona con un file SQLite locale o con un database libSQL ospitato.

## Materialize

CMS open source con editor visuale: le pagine si disegnano sulla tela, il sito è fatto di file statici veloci. Per un nuovo sito (serve Node 24):

```bash
npm create materialize@latest
```

Documentazione e codice: https://github.com/materializecms/materialize · Licenza MIT.

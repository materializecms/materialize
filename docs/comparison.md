# Materialize and other CMSs

An honest comparison, to help you tell whether Materialize is right for you or you need something else. Written in November 2026 and checked against the sources listed at the end. The other products change often, so check their sites before you decide. If you find a mistake, [open an issue](https://github.com/materializecms/materialize/issues).

> Materialize is in **Alpha**: it works and runs real sites, but it doesn't yet have the maturity, community and extensions of the products it's compared with here.

## In short

Materialize is an **open-source (MIT)** CMS for agencies, web designers and freelancers who build sites for clients:

- **The site is built on the canvas**, with more than 100 ready-made sections and the brand's colors and fonts: **no code needed**. Developers can add their own sections and content types in TypeScript, because the site is an Astro project.
- **Clients edit the real page on the canvas**, with the site's components and style, and can't break the design.
- **The published site is static**: HTML files that are fast, secure and easy to serve.
- **Everything in one program** on your server: panel, database (SQLite included), media, backups, updates.
- **AI inside the panel** (Claude, or a local model with Ollama), which writes in **your brand's voice** and prepares **the first version of the site from a few lines**, plus **MCP** to work on the site from Claude Desktop or Claude Code.

## CMS families

| Family                     | Examples                                       | How it works                                                                                       |
| -------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Traditional CMSs           | WordPress, Joomla, Drupal                      | Panel and site in the same PHP program, with themes and plugins.                                   |
| Subscription site builders | Webflow, Framer, Wix, Squarespace              | Visual editor, CMS and hosting in one paid service.                                                |
| Headless                   | Strapi, Payload, Sanity, Contentful, Storyblok | They manage content and serve it through an API; the site is a separate project to build and host. |
| For publishers             | Ghost                                          | Articles, newsletters and paid subscriptions.                                                      |
| File-based CMSs            | Statamic, Craft CMS, Decap                     | Content in files or in a PHP panel, often with Git.                                                |
| CMSs for Astro             | EmDash                                         | An Astro integration with a panel, API and MCP; a developer writes the site's pages.               |

Materialize sits in between. Like a site builder, the page is built on the canvas and the client edits it visually. Like a traditional CMS, it's a single program that does everything, on your server. Like a headless CMS, developers can define sections and content in code, because the site is an Astro project.

## When to choose Materialize

- You build sites for clients and want them to **edit on their own** texts, images and sections, without being able to break the design you made.
- You want **a fast static site** and a single program to keep up to date, **with no subscription** per site.
- You want to **build the site on the canvas**, with ready-made sections and your own style, **without writing code**.
- Or you're a developer and want to work with **Astro and TypeScript**, with the content schema in the repository like the rest of the code.
- You want to use **AI on your content** (writing, translations, SEO, pages from a reference image), paying only for what you use, or with a local model.
- You have a WordPress site to **migrate** and want to bring over articles, images, SEO and redirects.
- You want **WebGL and 3D effects** (animated backgrounds, the client's logo in chrome or glass, `.glb` models) without outside services or code: they're already there as ready-made sections, lightweight and with a still version for people who reduce motion.

## When to choose something else

- **You need a plugin ecosystem**, full e-commerce or shared hosting for a few euros: **WordPress**.
- **You don't want to run a server** and would rather pay for a service that does everything: **Webflow**, **Framer**, **Wix** or **Squarespace**.
- **You live off newsletters and subscriptions**: **Ghost**.
- **Your content feeds many apps** (site, mobile app, screens) or a large team works together in real time: **Sanity**, **Contentful**, **Storyblok** or **Payload**.
- **You have a developer who writes the site in Astro** and want a stable CMS with collections created from the panel, sandboxed plugins, passkey sign-in or serverless hosting on Cloudflare: **EmDash** (by Cloudflare, 1.0 in September 2026). It has no canvas or page builder, and no newsletter.
- **You need a mature product**, with commercial support and years of history: today Materialize is in Alpha.
- **The panel has to be in a language other than English and Italian**: for now there are only these two (panel, messages, emails, terminal and guide). The site's content can be in any language.

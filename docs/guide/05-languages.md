# Sites in several languages

## Adding a language

In **Settings → Languages**, an administrator chooses the site's languages. The first one is the **main language**: the one the site shows when no other is chosen.

## Translating a page

Each page has a language menu at the top (**Languages of this page**). From there, for a missing language:

- **Create the translation with AI**: creates the page in the new language with the text already translated, as a draft to review. You need the AI assistant set up (see [AI assistant](09-ai-and-mcp.md)).
- **Create a copy to translate by hand**: the same page with the same text, for you to translate.

Translations stay linked to the original. Use the menu to switch from one language to another.

**Match the original**: if you change the layout of the original page (new sections, different styles), the translation takes the structure and style from the original and keeps its translated text.

## What translates by itself

- **Menu and footer** (the shared sections): they have the same structure in every language, and only the words change. Translate them by opening the section in the language you want to translate.
- **Internal links**: a link to the "Chi siamo" page leads to "About us" in the English version.
- **Lists and template pages** show items in the page's language.

## The language switcher

In the editor, the **Language switcher** element (key **L**) adds links to the other languages on the site. It shows the codes (IT, EN) or the names (Italiano, English).

## In the panel

At the bottom left, choose the language of the content you're viewing in the lists.

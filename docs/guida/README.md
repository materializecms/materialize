# Guida di Materialize

Questa guida è per chi crea e gestisce siti con Materialize: agenzie, freelance e chi scrive i contenuti. Non serve saper programmare, tranne dove è detto esplicitamente.

> Materialize è in **Alpha**: funziona, ma può cambiare da una versione all'altra. Le novità di ogni versione sono nel [CHANGELOG](../../CHANGELOG.it.md).

## Per chi sviluppa

Lo schema dei contenuti, il sito Astro, i blocchi, le API e lo sviluppo di Materialize stesso sono descritti nel [README del progetto](../../README.md). Per mettere in sicurezza un server c'è la [guida alla sicurezza](../sicurezza.md).

## Due parole che tornano spesso

- **Pannello**: l'area di amministrazione, su `/admin` del tuo sito (per esempio `https://example.com/admin`).
- **Pubblicare**: le modifiche restano una bozza, visibile solo nel pannello, finché non premi **Pubblica**. Solo allora arrivano sul sito.
